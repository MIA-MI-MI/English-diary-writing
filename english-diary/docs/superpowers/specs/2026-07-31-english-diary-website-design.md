# 英语日记网站设计文档

**创建日期**: 2026-07-31  
**项目类型**: Web 应用（全栈）  
**目标用户**: 英语学习者（初期为教学场景，后期开放为公共社区）

---

## 一、项目概述

### 1.1 项目愿景
打造一个温馨治愈的英语写作练习平台，以纸质日记本的视觉风格，让用户享受写作过程的同时获得专业的 AI 批改反馈，提升英语写作能力。

### 1.2 核心价值
- **沉浸式体验**: 纸质日记本风格，手写字体，开锁动画，营造温馨治愈的写作氛围
- **智能辅助**: AI 动态生成主题，GPT 专业批改，提供精准的学习反馈
- **成长记录**: 完整的统计数据和心情分析，让用户看到自己的进步轨迹

---

## 二、功能需求

### 2.1 用户系统

#### 注册登录
- 邮箱 + 密码注册
- 邮箱 + 密码登录
- 登录动画：日记本封面 + 锁的动画
  - 输入时锁轻微晃动
  - 点击登录后锁打开
  - 日记本翻开过渡到主页面

#### 个人资料
- 昵称（可修改）
- 头像（默认提供几个温馨风格的头像）
- 密码（可修改）

### 2.2 每日主题

#### 功能描述
- 用户登录后首页显示当天的 AI 生成主题
- 主题基于日期、节日、季节等因素动态生成
- 用户可点击"换一个"按钮重新生成主题

#### 示例主题
- "Write about a memorable trip you've taken"
- "Describe your ideal weekend"
- "What made you smile today?"

### 2.3 日记写作

#### 输入要求
- 纯文本输入框
- 最少 300 字提示（未达标时友好提示，不强制阻止提交）
- 实时字数统计

#### 显示效果
- 输入时：普通字体便于编辑
- 提交后：显示为唯美手写风格英文字体

#### 自动保存
- 草稿自动保存（可选功能，后续迭代）

### 2.4 AI 批改功能

#### 批改流程
1. 用户提交日记
2. 调用 GPT-4 API 进行批改
3. 批改结果存储到数据库
4. 展示批改结果

#### 批改内容
- 语法错误识别
- 用词建议
- 句式优化建议
- 整体评语

#### 展示方式（批注式）
- 错误处用红色下划线标记
- 鼠标悬停显示具体批改意见
- 右侧显示老师的整体评语
- 提供修改建议示例

### 2.5 历史日记

#### 展示位置
- 主页面右侧侧边栏（占 30% 宽度）

#### 功能
- 按日期倒序排列历史日记
- 显示日期 + 主题预览
- 点击可查看完整日记和批改结果
- 滚动显示，有纸张翻页的感觉

### 2.6 个人中心

#### 基础统计
- 累计完成天数
- 总字数统计
- 总句子数统计

#### 心情分析
- 分析用户这段时间日记内容
- 展示主要心情倾向：
  - 喜 😊
  - 怒 😠
  - 哀 😢
  - 乐 😄
- 显示心情占比或主要心情图标
- 根据心情动态生成一句治愈的话语

#### 个人设置
- 修改昵称
- 修改密码
- 退出登录

## 三、视觉设计

### 3.1 整体风格
**纸质日记本风格 - 温馨治愈**

### 3.2 配色方案
- **主色**：
  - 米黄 #F5F1E8（纸张背景）
  - 浅棕 #E8DCC8（卡片背景）
- **强调色**：
  - 深棕 #8B7355（标题、按钮）
  - 墨绿 #6B8E6B（点缀装饰）
- **批改色**：
  - 红色 #C94C4C（批改标记）

### 3.3 字体方案
- **输入编辑**: 系统默认字体（便于编辑）
- **提交后显示**: 
  - 手写风格: Caveat / Dancing Script / Patrick Hand
  - 可在 CSS 中配置多种手写字体作为备选

### 3.4 装饰元素
- **角落贴纸**: 简约线条插画（咖啡杯、书本、花朵、猫咪等）
- **胶带效果**: 日记卡片顶部有半透明胶带装饰
- **阴影效果**: 轻微纸张阴影，增加立体感
- **日期戳**: 手写风格的日期显示

### 3.5 动画效果

#### 登录页动画
- 日记本封面静态展示
- 锁在输入时轻微晃动
- 点击登录后：
  1. 锁扣弹开动画（0.5s）
  2. 日记本翻开动画（0.8s）
  3. 淡入过渡到主页面（0.3s）

#### 其他微交互
- 按钮悬停：轻微放大 + 阴影加深
- 卡片悬停：轻微上浮
- 页面切换：淡入淡出

## 四、技术架构

### 4.1 前端技术栈
- **框架**: Next.js 14（App Router）
- **UI 库**: Tailwind CSS
- **字体**: Google Fonts（手写字体）
- **状态管理**: React Context + SWR（数据请求）
- **动画**: Framer Motion（登录动画等）

### 4.2 后端技术栈
- **API**: Next.js API Routes
- **数据库**: Supabase（PostgreSQL）
- **认证**: Supabase Auth

### 4.3 AI 集成
- **批改服务**: OpenAI GPT-4 API
- **主题生成**: OpenAI GPT-3.5-turbo
- **心情分析**: OpenAI GPT-3.5-turbo

### 4.4 部署方案
- **前端 + API**: Vercel（免费额度）
- **数据库**: Supabase（免费额度）
- **域名**: Vercel 默认域名或自定义域名

## 五、数据模型

### 5.1 用户表 (users)
```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  nickname VARCHAR(100),
  avatar_url VARCHAR(500),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

### 5.2 日记表 (diaries)
```sql
CREATE TABLE diaries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  word_count INTEGER,
  sentence_count INTEGER,
  theme TEXT,
  correction_result JSONB,
  mood VARCHAR(20),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

### 5.3 批改结果结构 (correction_result)
```json
{
  "overallComment": "整体评语",
  "corrections": [
    {
      "originalText": "原文片段",
      "correctedText": "修正后的文本",
      "errorType": "grammar/vocabulary/style",
      "explanation": "错误解释",
      "position": {
        "start": 0,
        "end": 10
      }
    }
  ],
  "score": 85
}
```

## 七、API 设计

### 7.1 认证相关
- `POST /api/auth/register` - 用户注册
- `POST /api/auth/login` - 用户登录
- `POST /api/auth/logout` - 退出登录
- `GET /api/auth/me` - 获取当前用户信息

### 7.2 日记相关
- `GET /api/diary/today` - 获取今日日记（如果有）
- `POST /api/diary` - 提交日记
- `GET /api/diary/history` - 获取历史日记列表
- `GET /api/diary/:id` - 获取特定日记详情

### 7.3 主题相关
- `GET /api/theme/today` - 获取今日主题
- `POST /api/theme/regenerate` - 重新生成主题

### 7.4 AI 相关
- `POST /api/ai/correct` - 批改日记
- `POST /api/ai/analyze-mood` - 分析心情

### 7.5 用户相关
- `GET /api/user/stats` - 获取统计数据
- `PUT /api/user/profile` - 更新个人资料
